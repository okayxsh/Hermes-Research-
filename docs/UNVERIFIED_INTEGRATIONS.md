# Unverified integrations

The following are deliberately not claimed to work: Hermes profile creation and `--no-skills`, Hermes plugin schema/hooks, Hermes skill-load events, Ollama model tags/digests, and ALFWorld runtime/data/API. The local HTTP bridge and its deterministic fake adapter are tested contract fixtures; they are not evidence that the real ALFWorld adapter works.

The pilot must capture installed versions, command help, capability-probe output, raw tool-call evidence, profile-isolation evidence, bridge logs, and reproducibility manifests before these become operational.
